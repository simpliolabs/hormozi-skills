# hormozi-skills

The Simpliolabs-maintained fork of an open-source, Hormozi-inspired skill library for coding agents. It supports standalone offer methods and a controlled one-chat orchestration workflow with business/claim checks, independent-review holds, and a structural SUMMARY contract.

**Upstream:** [alexsmedile/hormozi-skills](https://github.com/alexsmedile/hormozi-skills), created by Alex Smedile; original MIT license and attribution remain intact.

**Validated:** PR #3's bounded, fictional first-completion acceptance preserved seven specified obligation identities across six checker findings without operator repair. This is **not** authenticated independent-review execution or proof of general commercial readiness. See the [acceptance evidence](docs/SEVEN_HOLD_VALIDATION.md).
