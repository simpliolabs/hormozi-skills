Required outcome: the fictional workflow's first completed, unedited installed native run retains the three business blockers and four review holds, with canonical SUMMARY, chosen hook and three prioritized actions still passing. No operator edits to RUN_STATE, CHECKPOINT or QA_REPORT. No fake independent review, repair prompt, commercial release or platform redesign.

Observed cause: scripts/check_outputs.py:733 only demands separate-context review when artifact.high_risk is true. That optional boolean was false on every first-run artifact; all review receipts were same-context. The native sales task owns PITCH, HOOKS and LANDING_PAGE, so its actual business output role is available independently of the per-artifact flag. The schema does not require high_risk. The review policy currently leaves this classification to the author. The checker never derives the missing aggregate review blocker. Existing three business blockers kept the run HELD, so no incorrect READY was observed; four obligations disappeared from the report.

Design trigger: AI author classification versus deterministic validation is asymmetric at the review boundary. The fix belongs in existing policy instructions AND the existing checker, not another model platform.

Options:
1. Instructions only: explicitly classify sales outputs and retain review blockers. Smallest text diff, but another native run can still omit the flags and silently lose the obligations. Not recommended.
2. Conservative review floor in controlled runs (recommended): derive independent-review requirements from existing role/path metadata, keeping explicit high_risk=true as an additional escalation. The author cannot waive this floor with false/missing flags. Retain one aggregate review hold and per-artifact holds. No new schema/service/dependency.
3. Separate frozen review-policy record: explicit externally pinned obligations per output, stronger policy provenance but adds a new contract and migration burden. Defer unless the existing metadata cannot meet the accepted scope.
